TUTORIAL DE COMO USAR O SISTEMA DE BIBLIOTECA 


1. COMO ABRIR
- Extraia o arquivo ZIP.
- Abra o Apache NetBeans.
- Vá em File > Open Project.
- Selecione a pasta "SistemaBiblioteca".
- Aguarde o NetBeans reconhecer o projeto.
- Execute com F6 ou clique em Run Project.

2. FUNCIONALIDADES
- Gerenciamento de livros: cadastro, listagem e exclusão.
- Gerenciamento de membros: cadastro, listagem e exclusão.
- Empréstimos: seleção de livro disponível e membro.
- Devoluções: seleção de empréstimo e alteração do status.
- Navegação entre telas por botões do menu principal.

3. DADOS
Os dados são mantidos em ArrayList durante a execução do programa.
Ao encerrar o programa, os dados não são persistidos em banco de dados.

4. ESTRUTURA
model/Livro.java          -> modelo dos livros.
model/Membro.java         -> modelo dos membros.
model/Emprestimo.java     -> modelo dos empréstimos.
model/BibliotecaDados.java -> ArrayLists compartilhados.
view/TelaPrincipal.java   -> menu principal.
view/TelaLivros.java      -> tela de livros.
view/TelaMembros.java     -> tela de membros.
view/TelaEmprestimo.java  -> tela de empréstimos.
view/TelaDevolucao.java   -> tela de devoluções.
Main.java                 -> ponto de entrada.
