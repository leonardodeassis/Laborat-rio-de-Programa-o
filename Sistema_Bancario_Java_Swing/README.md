# Sistema Bancário - Java Swing

**Atividade Prática 03**  
**Aluno:** Leonardo

Projeto acadêmico desenvolvido com Java Swing e Apache NetBeans.

## Funcionalidades
- Cadastro de contas
- Depósito
- Saque
- Transferência
- Extrato
- Validação de saldo
- Mensagens de erro e sucesso

## Organização
O projeto aplica uma separação simples entre modelo, regras de negócio e interface.

## Entrega
O arquivo `LEIA-ME.txt` contém o tutorial de execução e um roteiro para gravação do vídeo.
